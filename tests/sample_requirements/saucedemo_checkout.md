# User Story: Sauce Demo E-Commerce Checkout

## Objective
As a standard customer on the SauceDemo e-commerce website, I want to log in with valid credentials, add the Sauce Labs Backpack product to my shopping cart, navigate to the cart, and verify that the items are ready for checkout.

## Target URL
`https://www.saucedemo.com`

## Acceptance Criteria
1. User navigates to `https://www.saucedemo.com`.
2. User enters `standard_user` into the username input field.
3. User enters `secret_sauce` into the password input field.
4. User clicks the Login button.
5. User clicks the Add to Cart button for Sauce Labs Backpack.
6. User clicks on the Shopping Cart container icon.
7. User verifies that the cart container displays the added item.
